Documentation

A quick reference for how each part of this admin platform works.

On this page

Dashboard Inventory Verification Transactions Profile

Dashboard

The Dashboard gives you a live snapshot of the platform: total listings, active bookings, the host verification queue, and total platform volume. Figures update immediately whenever you add, edit, or remove a listing, booking, or host approval anywhere else in the app.

Inventory

Inventory is the Property Directory — every stay listing on the platform. Use Add Listing to create a property (name, location, host, nightly price, and verification status). Photos are matched automatically from the location you enter, or you can paste your own photo URLs. Use the checkboxes to select multiple listings and delete them together, or open the ⋮ menu on a single row to edit or delete it. The Filter button narrows results by verification status, and Export Report downloads the currently filtered list as a CSV file.

Verification

New hosts who sign up on the TripMate site appear here automatically as pending applications — nothing is pre-populated. Click Review on an applicant to load their details into the Badge Preview panel, then Approve Host to verify them or Reject application to remove them from the queue without deleting their account.

Transactions

The Financial Overview tracks every booking as a transaction: a base rate (nights × nightly price), taxes/fees, and a 12% platform commission. Use the eye icon on any row to see the full breakdown. Export Report downloads the filtered ledger as a CSV, and Generate Statement downloads a summary statement with platform totals included.

Profile

Update your admin name, email, and phone, and choose whether you receive email or SMS notifications. Your "member since" date reflects the first time this admin panel was opened in this browser. Booking History shows real platform bookings — "Manage" jumps to that booking in the Transactions ledger, and "Book Again" opens a prefilled booking form for the same property.

Frequently asked questions

Why is my dashboard showing all zeros?

This admin panel starts empty. Add a listing under Inventory, then add a booking under Transactions, and every number across the app will update in real time.

How do new hosts get verified?

Anyone who signs up as a host on the TripMate site shows up under Verification automatically. Review their application, then approve or reject it.

Where does the "commission" number come from?

It's calculated as 12% of each booking's base rate (nights × nightly price), matching the same rate used for taxes/fees.

Can I export my data?

Yes — both the Inventory and Transactions pages have an "Export Report" button that downloads the currently filtered table as a CSV file.
